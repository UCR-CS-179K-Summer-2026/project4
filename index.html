Class/struct structure

DeclaredVariable (struct)

  • name - the variable's identifier
  • line - the line number (relative to the start of its function's body) where it was declared

FunctionInfo (struct)

  • functionStart - the function's signature/declaration text (e.g. int calculateCost(int itemPrice, int tax) {)
  • functionBody - the full text of the function's body
  • line - the line number where the function body begins
  • variables - a vector of DeclaredVariable, populated by Parser with every variable declared inside this function

ParsedSource (struct)

  • source - the raw, unmodified source code (including comments) — kept as-is since some detectors, like the comment checker, need to inspect comments directly
  • functions - a vector of FunctionInfo, one per parsed function in the file

Parser (class)

  • parse() - the only public method; takes the opened input file, reads it once, and returns a fully-populated ParsedSource (source + functions + each function's declared variables). This is called exactly once in main.cpp, and the resulting ParsedSource is reused by every detector, instead of each detector re-parsing the file independently.

Detector (abstract base class)

  • analyzeSource(const ParsedSource&) - pure virtual; every detector subclass implements this to scan the shared parsed data and return its warning count, printing warnings to the terminal as it finds them
  • Virtual destructor, since detectors are used polymorphically

RedundantCodeChecker (extends Detector)

  • Implements analyzeSource() to check each function's already-parsed variables for whether they're referenced again elsewhere in that function's body

SmellyCodeDetector

  • Owns one Parser and one instance of each individual detector (e.g. RedundantCodeChecker, PoorNameChecker)
  • Constructor takes the opened input file and immediately parses it via Parser::parse(), storing the result in parsedSource
  • runDetectors() - calls analyzeSource(parsedSource) on every detector and sums their returned warning counts into one total

Inferences of Modules

Parser.cpp

  • splitIntoFunctionBodies() - finds functions in the source code file and isolates each function's body, along with its starting line, into a FunctionInfo (so variables in different functions aren't mixed up with each other).
  • stripComments() - removes // and /* */ comments before analysis, so commented-out code doesn't produce false declarations or false usages
  • findDeclarations() - finds variable declaration statements within a function body (e.g. int x;, int x = 5;, int a, b;) and extracts each declared variable's name and line number into a DeclaredVariable.
  • buildTypePattern() - builds the regex pattern used by findDeclarations() to recognize supported type keywords (int, float, bool, etc.) at the start of a declaration.
  • parse() - orchestrates the above: reads the input file in one go, strips comments, splits into function bodies, attaches each function's declared variables, and returns a ParsedSource shared by every detector.

poorNaming.cpp

  • searchVariableNames() - searches for all variable names found in the source code. Returns all of the found variables
  • isPoor() - Accepts a string and determines whether the string is poor or not. It will return an empty list if not poor, or a list of recommendations if it is poor.

repeatedCode.cpp

  • stripBlockComment() - detects and removes blocked comments
  • stripLineComment() - detects and removes single line comments
  • normalizeWhiteSpace() - deletes whitespace to prevent false negatives
  • extractCodeLines() - using the cleaned code regex, return the vector containing the lines of code
  • reportRepeatedBlock() - from the extracted code lines, check for repeated blocks. If found, emit the warning message.

redundantCodeChecker.cpp

  • analyzeSource() - inherited from Detector; iterates over every FunctionInfo in the shared ParsedSource and, for each of its already-parsed variables, checks whether that variable is ever referenced again.
  • countUsages() - counts how many times a given variable name appears as a whole word within a function's body, used to determine whether a declared variable is ever referenced again.

commentChecker.cpp

  • analyzeSource() - inherited from Detector, iterates over source from parser to find uncommented functions. Supports comments in the line before a function, not counting whitespace, inline comments, comments in the body of the function, and comments at the end of the function (closing bracket line)

API's and Their Usage

  • Regex - used to strip comments, identify function boundaries, find variable declaration statements, and count variable usages within the source file.
  • Fstream - enables our input to be read from a C++ source file (std::ifstream).
  • Sstream - std::stringstream reads the entire file into one string in a single pass (rdbuf()); std::istringstream is used to split a function's body back into individual lines when locating declaration line numbers.
  • Vector - stores the parsed structures shared across all detectors: ParsedSource::functions (a vector of FunctionInfo), and FunctionInfo::variables (a vector of DeclaredVariable), the candidates each detector inspects for smells.
  • String - used to store the raw source code, each function's body text, individual variable names, and the regex pattern strings themselves.

Algorithms and Optimizations

  • Parallelism - Once the source code is parsed once by Parser, SmellyCodeDetector::runDetectors() currently calls each detector's analyzeSource() sequentially.
  • Hashmaps - instead of using pairwise comparison, we use a hashmap to check for cases such as repetitions.
  • Single compilation for regex - Applied for the fixed, name-independent patterns: declRegex, declaratorRegex, and funcStartRegex in Parser.cpp. They are all declared static const, so they compile once on first use rather than on every call.
  • Memoization - Function bodies are parsed and stored once in each FunctionInfo::functionBody, and declared variables are stored once in FunctionInfo::variables, both computed a single time in Parser::parse() and reused by every detector afterward.
  • Single-read files - Parser::parse() reads the entire input file into one string in a single pass via rdbuf(). Parsing happens once in main.cpp (via SmellyCodeDetector) instead of once per detector, so the file is read exactly once for the whole program.
