Warnings your compiler
won't give you.

A static analysis tool that reads a single C++ source file once, then hands the parsed result to a set of independent detectors — each one hunting a different code smell, from dead variables and deeply nested conditionals to copy-pasted blocks, unreachable and unused functions, bloated parameter lists, data clumps, redundant inheritance, and unfreed memory — and printing what it finds straight to the terminal.

How to Build

// 01  pipeline

Architecture

One parse, many detectors. The source file is read exactly once and turned into a shared ParsedSource; every detector below just reads from it and hands back its own list of Warnings, which SmellyCodeDetector merges, sorts, and prints.

// 02  data model

Class & Struct Structure

Structs carry data between stages; classes carry behavior. Every detector is a subclass of the same abstract Detector, so SmellyCodeDetector can run all of them the same way and collect their results into one shared list.

struct

ParsedSource

  • source — the raw, unmodified source code (including comments), read once from the input file.
  • tree — a TSTree*, the full tree-sitter parse tree for that source. This replaced the old pre-sliced function/variable data entirely — every detector walks this tree directly instead.

struct

Warning

  • line — the source line the warning applies to.
  • category — a short label identifying which check raised it, e.g. "Poor Naming", "deep-if", "repeated-code".
  • message — the human-readable warning text.

class

Parser

  • parse() — the only public method. Reads the opened input file into source in one pass via a stringstream's rdbuf(), spins up a TSParser configured for the tree_sitter_cpp() grammar, and parses that raw source directly into a TSTree.
  • Called exactly once, in main.cpp; the resulting ParsedSource is reused by every detector instead of each one re-parsing the file independently.
  • Fails safely — if the tree fails to build, it logs an error to stderr, cleans up the parser, and returns ParsedSource{source, nullptr} rather than crashing. Every detector already checks for a null tree before walking it.

abstract base class

Detector

  • analyzeSource(const ParsedSource&) — pure virtual; every subclass implements this to walk the tree and return a std::vector<Warning> of everything it found.
  • visitNode(TSNode, const ParsedSource&, std::vector<Warning>&) — also part of the interface; each subclass's recursive tree-walk, dispatching to its own checks by node type and appending to the shared warnings vector. Detectors no longer print anything themselves — output is centralized in SmellyCodeDetector.
  • Virtual destructor, since detectors are used polymorphically

class

CommentChecker extends Detector

  • Walks the tree for function_definition nodes and checks the immediately preceding sibling for a comment node
  • Falls back to recursively scanning the function's body for any interior or inline comment
  • Also checks for a trailing comment on the same source line as the function's closing brace
  • Flags any function matching none of the above as having no comments

class

PoorNameChecker extends Detector

  • Traverses the tree searching for declaration or function_definition nodes
  • For declarations, resolves the identifier out of identifier, init_declarator, or array_declarator children before checking it
  • For functions, delegates the function name and each parameter name to FunctionAnalyzer
  • Checks every resolved name's validity via NameAnalyzer

class

NameAnalyzer

  • Extracts a variable's identifier name from the raw source using its byte offsets
  • Finds the line number a given node starts on
  • Depth-first searches a subtree for its first identifier node
  • Determines whether a name is poor using a length heuristic (with exceptions for common loop counters) plus regex checks for boolean-prefix naming, generic function verbs, and generic placeholder names like temp or data
  • Given a name and line, appends a formatted "Poor Naming" warning

class

FunctionAnalyzer

  • Checks whether a function's name is poor, using NameAnalyzer's methods
  • Iterates a function's parameter list and checks each parameter's name via NameAnalyzer

class

RedundantCodeChecker extends Detector

Checks implemented

  • Unused/dead variables — declared but never referenced again within their own scope, correctly handling shadowing
  • Redundant boolean comparisons — x == true, x != false, etc.
  • Redundant if/else returning boolean literals — if (cond) return true; else return false;
  • Chained if-statements that should be if/else if/else — consecutive sibling ifs that each unconditionally return, with no else

class

DeadCodeChecker extends Detector

Checks implemented

  • Unreachable code — walks each block's statements in order; once one is found to unconditionally exit (via return/break/continue/goto, or an if/else where both branches always exit), every sibling statement after it in that block is flagged
  • Unused/dead functions — builds a call graph of every top-level function to the names it calls, then runs an iterative DFS from main to compute which functions are actually reachable; anything defined but unreachable (and not main itself) is flagged
  • Skips the unused-function check entirely if the file has no main, since reachability can't be determined

class

RepeatedCodeChecker extends Detector

  • Scans each function's compound_statement blocks for runs of consecutive statements repeated elsewhere in the same block
  • Structurally hashes each statement subtree so identical statements collide to the same key, regardless of exact source formatting
  • Slides a window across the block's statements, largest size first, grouping candidates by hash in an unordered_map
  • Confirms every hash match with a full structural comparison before reporting, to rule out collisions

class

DeepIfDetector extends Detector

  • Tracks nesting depth as it recurses, incrementing on entering an if_statement and decrementing on the way back out
  • Flags any if_statement whose depth exceeds MAX_DEPTH as a "deep-if" warning

class

LongParamList extends Detector

  • Traverses the tree for function_definition nodes
  • Counts each function's declared parameters and flags it once the count exceeds a defined threshold
  • Resolves the function's full name via the same identifier/declarator walk used elsewhere, for the warning message

class

DataClumpDetector extends Detector

  • Searches the tree for function_definition and compound_statement nodes
  • Inside a block, groups variables that are declared together and arguments that are passed together into the same call, using each group as a key into a map
  • The map's value, ClumpInfo, tracks how many times that exact group of names occurred and at which line numbers
  • Also checks a function's own parameter list for the same recurring groupings
  • Any group that recurs often enough is reported as a data clump, with every occurrence's line number listed

class

InheritanceChecker extends Detector

  • Traverses the tree for class_specifier nodes
  • For each class that actually inherits from a base class, scans its body for evidence the inheritance is being used: overridden functions, calls to the base class's functions, or a constructor call into the base class
  • If none of those three signals are present, the inheritance is flagged as redundant

class

MemoryChecker extends Detector

  • Tracks every memory allocation it sees, keyed by variable name and location, in trackedAllocations
  • Walks the function body and, at every if statement, branches into each possible path so both sides of a conditional are checked independently
  • Flags any path that reaches a return without the corresponding allocation having been freed first

class

SmellyCodeDetector

  • Owns one Parser and one instance of every registered detector — PoorNameChecker, RedundantCodeChecker, DeadCodeChecker, RepeatedCodeChecker, CommentChecker, DeepIfDetector, and LongParamList — held as member objects and registered into a std::vector<Detector*> in the constructor
  • Constructor takes the opened input file and immediately parses it, storing the result in parsedSource
  • runDetectors() — calls analyzeSource(parsedSource) on every detector, merges all returned warnings into one list, sorts by line (tie-broken by category), prints each one, and returns the total warning count

// 03  code structure

Code Structure

One file per concern. Each module owns a single smell, or the parsing/orchestration that feeds all of them.

Parser.cpp

  • Reads the input file once and builds the shared tree-sitter TSTree, returning it as a ParsedSource.

SmellyCodeDetector.cpp

  • Parses the input file once at construction and owns one instance of every detector; runDetectors() merges, sorts, and prints all of their warnings.

commentChecker.cpp

  • Flags functions with no preceding, interior, or trailing comment.

poorNameChecker.cpp

  • Finds variable, function, and parameter declarations in the tree and hands their names off to NameAnalyzer.

NameAnalyzer.cpp

  • Shared naming heuristics — length checks and regex patterns — used by both PoorNameChecker and FunctionAnalyzer.

FunctionAnalyzer.cpp

  • Applies NameAnalyzer's checks specifically to function names and parameter lists.

redundantCodeChecker.cpp

  • Unused variables, redundant boolean comparisons, redundant if/else boolean returns, and chained-if patterns — four checks in one traversal.

deadCodeChecker.cpp

  • Unreachable code after an unconditional exit, and unused/dead functions unreachable from main via a call graph.

repeatedCodeChecker.cpp

  • Finds duplicated runs of statements inside a function body using structural AST hashing and a sliding window.

DeepIfDetector.cpp

  • Flags if statements nested past a fixed depth.

longParamList.cpp

  • Flags functions whose parameter count exceeds a defined threshold.

DataClumpDetector.cpp

  • Flags variables or arguments that repeatedly appear together, suggesting they belong in their own type.

inheritanceChecker.cpp

  • Flags classes that inherit from a base class without ever using that inheritance.

memoryChecker.cpp

  • Flags paths where allocated memory isn't freed before a function returns.

// 04  internal api

Internal API

The actual functions each module exposes, grouped by file.

Parser

  • ParsedSource parse(std::ifstream& inputFile) — reads the file once into source via rdbuf(), builds the tree-sitter TSTree using the tree_sitter_cpp() grammar, and returns ParsedSource{source, tree} (or {source, nullptr} on parse failure, logging to stderr rather than crashing)

SmellyCodeDetector

  • SmellyCodeDetector(const std::ifstream& inputFile) — parses the file immediately and registers one instance of every detector
  • int runDetectors() — runs analyzeSource() on every detector, merges the results, sorts by line then category, prints "Warning: [category]. message(line N)" for each, and returns the total count

commentChecker.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — initializes tree-sitter, walks the tree, and returns every "no comments" warning found
  • void visitNode(TSNode, const ParsedSource&, std::vector<Warning>&) — recurses the tree, checking each function_definition for a preceding, interior, or trailing comment
  • bool scanForComments(TSNode) — recursively searches inside a function for any comment node

poorNameChecker.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — visits the tree's root node and returns all naming warnings found
  • void visitNode(...) — dispatches declaration nodes to checkVariableDeclaration() and function_definition nodes to checkFunctionDefinition()
  • void checkVariableDeclaration(...) — resolves the identifier from an identifier, init_declarator, or array_declarator child, then checks it against NameAnalyzer::isPoorName()
  • void checkFunctionDefinition(...) — delegates the function's name and parameters to FunctionAnalyzer

NameAnalyzer.cpp

  • std::string extractIdentifierName(const ParsedSource&, TSNode) — pulls a node's exact text via its byte offsets
  • int getLineNumber(const ParsedSource&, TSNode) — counts newlines before the node's start byte
  • TSNode findIdentifierNode(TSNode) — depth-first search for the first identifier descendant
  • bool isPoorName(const std::string& name, const std::string& type) — flags names under 3 characters (barring i, j, k, id), booleans that don't start with is/has/can/should/was/will, function names built from generic verbs like process or handle, and generic placeholder names like temp or val
  • void outputErrorMessage(const std::string& name, const int& line, std::vector<Warning>&) — appends a formatted "Poor Naming" warning

FunctionAnalyzer.cpp

  • void checkFunctionName(TSNode functionDeclarator, ...) — extracts the function's identifier and checks it via NameAnalyzer::isPoorName(name, "function")
  • void checkParameterNames(TSNode functionDeclarator, ...) — iterates the parameter list, checking each parameter_declaration's identifier and type

redundantCodeChecker.cpp

  • void visitNode(...) — single recursive walk, dispatching by node type (function_definition, binary_expression, if_statement, compound_statement)
  • std::vector<Warning> analyzeSource(const ParsedSource&) — gets the tree's root node, kicks off visitNode(), returns all warnings found
  • std::string nodeText(TSNode, const std::string&) — extracts a node's exact source text via its byte offsets
  • void checkUnusedVariables(...) — flags variables declared but never referenced again, scoped per-declaration to correctly handle shadowing
  • extractIdentifierFromDeclarator() / collectDeclarations() — resolve declared variable names from a declaration node, including pointers and comma-separated declarations
  • findEnclosingScope() — walks up from a declarator to the nearest enclosing compound_statement, so usage counting starts from the declaration's own scope
  • blockRedeclares() — checks whether a block directly redeclares a given name, used to detect shadowing
  • countIdentifierOccurrences() — counts references to a name within a subtree, skipping into any nested block that redeclares the name
  • checkBooleanComparison() — flags x == true / x != false-style comparisons and suggests the simplification
  • checkRedundantIfElseReturn() / unwrapToReturnStatement() — flags if/else branches that both return opposite boolean literals
  • checkChainedReturnIfs() / alwaysReturns() / getLastStatement() — flags consecutive if-statements, each returning unconditionally with no else; getLastStatement() skips brace tokens and comments to find a block's real final statement, which alwaysReturns() checks is itself a return

deadCodeChecker.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — runs visitNode() for unreachable-code (Check 5), then checkUnusedFunctions() once for unused functions (Check 6), and returns everything found
  • void visitNode(...) — dispatches only on compound_statement nodes, since both checks operate at block/file level rather than per-expression
  • std::string nodeText(TSNode, const std::string&) — extracts a node's exact text via byte offsets
  • TSNode getLastStatement(TSNode) — walks a block's children, skipping brace tokens and comments, to find its final real statement
  • bool alwaysExits(TSNode) — true if a statement unconditionally exits via return/break/continue/goto, or (for an if) has an else where both branches always exit; recurses through compound_statement and else_clause wrappers
  • void checkUnreachableCode(...) — walks a block's direct children in order; once one satisfies alwaysExits(), every later sibling in that block is flagged
  • std::string getFunctionName(TSNode) — resolves a function_definition's declarator down to its identifier
  • std::set<std::string> collectCalledFunctionNames(TSNode) — scans a function body for call_expression nodes and collects each callee's name (plain identifier calls only)
  • void checkUnusedFunctions(...) — collects every top-level function, skips the check if no main exists, builds a call graph via collectCalledFunctionNames(), runs an iterative DFS from main to compute the reachable set, and flags any defined function outside it

repeatedCodeChecker.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&)
  • void visitNode(...) — finds every function_definition, extracts its name, and scans its body
  • void scanBlocksForRepeats(...) — recurses into compound_statement blocks (skipping nested functions) and runs findRepeatedBlocks() on each
  • void findRepeatedBlocks(...) — slides windows of decreasing size across a block's statements, keyed by a combined hash, to find repeated non-overlapping runs
  • size_t hashSubtree(TSNode, const std::string&) — structurally hashes a subtree so identical statements hash identically
  • bool subtreesEqual(TSNode, TSNode, const std::string&) — full structural comparison used to confirm a hash match isn't a collision
  • std::vector<TSNode> collectStatements(TSNode blockNode) — gathers a block's named, non-comment child statements
  • extractFunctionName() / findIDNode() — resolve a function's name via its declarator
  • reportRepeatedBlock(...) — builds one warning listing every line range a repeated block occurs at, plus the code itself

DeepIfDetector.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&)
  • void visitNode(...) — increments a depth counter on entering each if_statement, flags it if depth exceeds MAX_DEPTH, then decrements on the way back out

longParamList.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — runs visitNode() over the whole tree
  • void visitNode(...) — finds function_definition nodes, counts parameters, and emits a warning once the count exceeds the threshold
  • TSNode findIDNode(TSNode) — locates an identifier node within a subtree
  • std::string extractFunctionName(...) — resolves a function's declarator, then calls findIDNode() to get its full name
  • void reportLongParamList(...) — outputs the warning message

DataClumpDetector.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — checks for data clumps at the end of its traversal
  • void visitNode(...) — searches for function_definition or compound_statement nodes, continuing the traversal otherwise
  • void checkInsideFunction(...) — on a compound_statement, groups variables declared together and pushes each group into a map keyed by that group, tracking how often it recurs; also collects call-expression arguments the same way
  • void checkCallExpression(...) — helper that pulls a call's arguments into the vector used as the map key
  • void checkFunctionParams(...) — checks whether a function's parameter set is frequently reused, keyed the same way
  • void checkForDataClumps(...) — reads the class-level map (key: vector of variable names, value: a ClumpInfo{counter, lineNumbers} struct) and builds a warning listing every variable and line number for groups that recur often enough

inheritanceChecker.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — runs visitNode() from the tree's root
  • void visitNode(...) — traverses the tree for class_specifier nodes and calls checkClass() on each
  • std::string nodeText(TSNode) — extracts a node's raw text
  • TSNode findChildByType(...) — returns a node's child matching a given type
  • std::string extractBaseClasses(TSNode) — determines whether a class actually inherits, returning its parent class's name if so
  • bool scanForInheritance(TSNode) — checks a class body for overridden functions, base-class function calls, or a base-class constructor call; any one of these means the inheritance isn't redundant
  • void checkClass(TSNode) — for an inheriting class, scans its body via scanForInheritance(); if none of the three usage signals are found, prints a redundant-inheritance warning

memoryChecker.cpp

  • std::vector<Warning> analyzeSource(const ParsedSource&) — clears trackedAllocations, then runs visitNode()
  • std::string getNode(TSNode) — same byte-offset text extraction as redundantCodeChecker's nodeText()
  • void visitNode(...) — base case; checks that every memory allocation has a corresponding deallocation before a return
  • void traverse(...) — branch case; at each if statement, calls visitNode() down every possible path to check whether any path reaches a return with memory still allocated
  • trackedAllocations — list of unfreed allocation locations and variable names found so far
usage — SmellyCodeDetector 
std::ifstream inputFile("example.cpp");
SmellyCodeDetector detector(inputFile);
int warningCount = detector.runDetectors();

// 05  dependencies

Dependencies

tree-sitter

Builds the TSTree for the source file in Parser::parse(), using the tree_sitter_cpp() grammar. Every detector walks this tree directly via TSNode traversal instead of pre-sliced text.

fstream

Reads the input from a C++ source file via std::ifstream.

sstream

std::stringstream reads the whole file into ParsedSource::source in one pass via rdbuf(); std::istringstream is used to split a body back into individual lines when locating declaration line numbers.

regex

Powers NameAnalyzer::isPoorName()'s boolean-prefix, function-verb, and generic-placeholder pattern checks.

unordered_map

Groups candidate statement windows by structural hash in RepeatedCodeChecker, and represents DeadCodeChecker's call graph (function name → set of names it calls) for the unused-function check.

set

Holds the DFS-visited/reachable set of function names in DeadCodeChecker::checkUnusedFunctions(), so a function reachable through more than one call path is only processed once.

vector

Carries each detector's std::vector<Warning> results back to SmellyCodeDetector, plus internal working lists like collected declarations, statements, or the DFS stack.

string

Stores the raw source, node text extracted via byte offsets, and variable/function names pulled from the tree.

// 06  performance

Algorithms & Optimizations

Single-read files

Parser::parse() reads the entire input into one string in a single pass via rdbuf() — the file is read exactly once for the whole program.

Single parse, shared tree

The TSTree is built once in Parser::parse() and reused by every detector afterward, instead of each detector re-parsing the source.

Exact line numbers from the AST

Warnings use ts_node_start_point() directly against the original source, rather than manually tracked line offsets.

Structural hashing

RepeatedCodeChecker hashes each statement subtree once, then groups window-sized runs by a combined hash in an unordered_map — avoiding pairwise comparison across a function body. Only same-hash candidates pay for the full structural equality check that guards against collisions.

Largest-window-first sliding search

findRepeatedBlocks() tries the largest possible repeated window before smaller ones and marks matched statements as covered, so a big repeated block isn't also reported as several smaller overlapping ones.

Depth-tracked traversal

DeepIfDetector increments/decrements a counter as recursion enters and exits if_statement nodes, flagging only once nesting passes MAX_DEPTH, instead of a separate pass to compute nesting depth per node.

Call-graph reachability

DeadCodeChecker builds a directed call graph from the file's function definitions and runs an iterative, stack-based DFS from main, tracking visited functions in a set — any defined function the DFS never reaches is unused/dead code.

Centralized sort & print

Detectors return warnings rather than printing them, so SmellyCodeDetector::runDetectors() can merge everything and sort once by line (then category) before printing a single ordered report.

Parallelism

runDetectors() currently runs each detector's analyzeSource() sequentially — a candidate for future parallel work.
